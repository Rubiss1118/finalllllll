## 📋 Descripción

Una aplicación web completa de Pokédex que permite a los usuarios gestionar su propia colección de Pokémon. La aplicación incluye sistema de autenticación, perfil de usuario y funcionalidades completas de CRUD para la gestión de Pokémon.

## ✨ Características Principales

- 🔐 **Sistema de Autenticación**: Inicio de sesión seguro para usuarios
- 👤 **Perfil de Usuario**: Vista personalizada con información del usuario
- 📱 **Pokédex Interactiva**: Gestión completa de Pokémon con operaciones CRUD
- 🎯 **Interfaz Intuitiva**: Diseño responsive y fácil de usar
- 🔍 **Búsqueda y Filtros**: Encuentra Pokémon rápidamente

## 🚀 Funcionalidades

### Autenticación
- Registro de nuevos usuarios
- Inicio de sesión seguro
- Gestión de sesiones
- Cerrar sesión

### Perfil de Usuario
- Visualización de datos personales
- Estadísticas de la colección
- Configuración de cuenta

### Gestión de Pokémon
- **Crear**: Agregar nuevos Pokémon a la Pokédex
- **Leer**: Visualizar lista completa de Pokémon
- **Actualizar**: Editar información de Pokémon existentes
- **Eliminar**: Remover Pokémon de la colección
- **Detalles**: Vista detallada de cada Pokémon con:
  - Información básica (nombre, tipo, nivel)
  - Estadísticas de combate
  - Imagen del Pokémon
  - Movimientos y habilidades
